# ORBIT CARE

A mobile-first wellbeing concept for space crews: emotion check-ins, optional health prompts, crew connection, private reflection, and asynchronous connection with home.

## Current design baseline

- `lowfi.html`: Eight editable grayscale mobile wireframes, each 390 × 844 px. Open directly in a browser or import with html.to.design.
- `color-palette.html`: Approved dark theme palette and usage examples. Import at 1200 px wide.
- `colors.css`: Approved color values for the upcoming interactive app.

The wireframes intentionally remain grayscale. The palette defines the visual direction for the app implementation.

## Screens

Home, Emotion Check-in, Health Alert, Check-in Complete, Support Hub, Common Room, Haven, and Tether.

## Next implementation

Build a responsive, single-screen-at-a-time web app with detailed emotion selection, browser-local check-in history, optional simulated health alerts, and support interactions. Additional screens and states can extend the eight-screen design baseline.

## Demo boundaries

All health readings and crew messages are fictional. No wearable, medical diagnosis, real messaging, or authentication service is connected. Current wireframe entries clear on reload. Live hosting has not been configured.
